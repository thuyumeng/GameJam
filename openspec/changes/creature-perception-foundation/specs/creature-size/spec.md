## ADDED Requirements

### Requirement: 统一体型数值

每个生物实体(动物与玩家)SHALL 持有单一的 Size 标量作为其在食物链中的唯一度量。系统 SHALL 通过任意两个实体的 Size 之比来判定它们的捕食关系,而不依赖物种、类型或其他属性。

#### Scenario: 实体拥有体型值
- **WHEN** 一个生物实体被生成
- **THEN** 该实体持有一个大于 0 的 Size 数值,可被其他实体读取用于比较

#### Scenario: 捕食关系仅由体型决定
- **WHEN** 系统判定实体 A 与实体 B 的捕食关系
- **THEN** 判定结果仅取决于 A.Size 与 B.Size 之比,与物种或类型无关

### Requirement: B 规则捕食阈值与灰色地带

系统 SHALL 使用一个可配置的体型比阈值 T(默认 1.2)将两个实体的体型关系分为三档:

- 当 `A.Size / B.Size >= T` 时,A 视 B 为**猎物**(可捕食)。
- 当 `B.Size / A.Size >= T` 时,A 视 B 为**天敌**(会被捕食)。
- 其余情况(体型比落在 `1/T` 与 `T` 之间)为**灰色地带**,双方互为**势均力敌**,谁都不能捕食对方。

阈值 T SHALL 可在数据层配置,不得硬编码在多处。

#### Scenario: 明显更大可捕食
- **WHEN** A.Size 为 12,B.Size 为 10,阈值 T 为 1.2
- **THEN** A 将 B 分类为猎物,B 将 A 分类为天敌

#### Scenario: 体型接近落入灰色地带
- **WHEN** A.Size 为 11,B.Size 为 10,阈值 T 为 1.2
- **THEN** A 与 B 互相分类为势均力敌,双方均不能捕食对方

#### Scenario: 阈值可配置
- **WHEN** 阈值 T 从 1.2 调整为 1.5
- **THEN** 体型比 1.3 的一对实体从"可捕食"变为"势均力敌",分类结果随配置改变

### Requirement: 体型与速度反相关

生物的最大移动速度 SHALL 随其 Size 增大而单调下降。系统 SHALL 提供一个从 Size 映射到移动速度的可配置关系,使得体型越大移动越慢、体型越小移动越快。

#### Scenario: 大体型移动更慢
- **WHEN** 实体 A 的 Size 大于实体 B 的 Size
- **THEN** A 的最大移动速度不高于 B 的最大移动速度

#### Scenario: 体型变化即时影响速度
- **WHEN** 一个实体的 Size 增大
- **THEN** 该实体的最大移动速度相应下降,无需重新生成实体
